# 대화 정리 (2026-11-12)

Claude와 나눈 대화에서 나온 요청, 결정, 결과를 순서대로 정리했습니다. 대화 원문이 아니라 요약입니다.

## 1. 시작
- Playwright CLI(0.1.24)와 Claude Code용 Playwright 스킬을 설치했습니다. 클라우드 환경 시작 스크립트에 넣을 설치 명령도 정리했습니다.
- 목표를 정했습니다: **휴대폰만으로** 사진을 주면 기존 블로그 스타일대로 리뷰를 써서 **임시저장까지** 하는 것.

## 2. 기존 글 학습
- 블로그 글 197개를 수집했습니다(RSS에는 최근 50개만 있어서 모바일 API로 전체를 받음).
- **협찬 글은 제외했습니다.** 체험단 배너(reviewnote, cloudfront, dinnerqueen, revu 등)나 "제공받아 작성" 문구로 판별했고, 64개였습니다.
- **조회수가 많은 글을 1순위로 학습했습니다.** 처음에는 공감+댓글로 대신했고, 로그인한 뒤 실제 조회수로 바꿨습니다.
- 오타는 바로잡아 해석했습니다.
- 고정 문장 "메뉴판 사진 속 … 100% 팩트 기반"은 쓰지 않기로 했습니다.
- 이모지 사용법과 서식(색·굵게·크기)을 분석했습니다. 반응 좋은 글은 이모지를 글당 약 47개 썼습니다.

## 3. 첫 글: 마곡 쿠로카메 라멘
- 사진은 Google Drive `블로그` 폴더로 받았습니다. 커넥터는 1파일 약 5MB까지라 6.4MB 사진 1장은 받지 못했습니다.
- 사진만으로 모르는 정보(웨이팅, 주차, 맛)는 **"쿠로카메" 검색 상위 블로그 10개**에서 공통 내용을 가져와 은똥잉 말투로 새로 썼습니다. 문장을 그대로 베끼면 점검에서 걸립니다.
- 세로 사진은 가로 4:3으로 잘랐습니다. 90도 회전은 내용이 눕기 때문에 쓰지 않았습니다.
- 미리보기는 비공개 아티팩트로 올렸습니다. 휴대폰 앱의 파일 보기는 HTML을 코드로 보여주기 때문입니다.

## 4. 검색 노출 연구
- 인기 맛집 글 40개(10개 지역 키워드 상위)를 분석했습니다. 73%가 가운데 정렬·짧은 줄이었고, 37%가 영상을 넣었고, 제목은 평균 35자였습니다.
- 검색 화면 순서: 플레이스 → 클립 → 브랜드 콘텐츠 → 블로그·카페 후기. 상위 글 40개 중 35개가 5주 안에 쓴 글이었습니다.
- 은똥잉 글의 순위: 가게명 검색어는 1~15위, "마곡 맛집" 같은 큰 키워드는 30위 밖이었습니다.
- **실제 조회수로 본 결론**: 조회수는 서식보다 **가게 선택**에서 갈립니다. 화제성·큰 상권·프랜차이즈 신메뉴 글이 상위였고, 강서권 동네 글은 하위에 몰렸습니다. 추천 비율은 화제·큰 상권 2 : 강서권 1입니다.
- **유입 검색어**: 75%가 상위 20위 밖의 긴 꼬리 검색어였습니다. 지역 키워드 중 1위는 `마곡 원그로브 맛집`(569회)처럼 건물·상권 이름이 들어간 형태였습니다.
- 검색광고 API 키를 연결해서 **실제 월간 검색수**로 키워드를 고릅니다.
- 반복 검토를 2회 했습니다. 규칙 충돌을 정리하고, 점검 항목을 20개에서 25개, 다시 27개로 늘렸습니다.

## 5. 사진·영상 처리
- 영상은 GIF로 만들어 넣습니다(3~4초, 720px). 원본 영상은 클립·본문 동영상으로 따로 올리기를 권장합니다.
- **사람 얼굴은 모두 모자이크합니다(필수).** 확실한 얼굴(0.75 이상)은 자동으로 가리고, 애매한 후보는 Claude가 눈으로 확인합니다. 음식 무늬를 얼굴로 잘못 잡는 문제를 이 방식으로 해결했습니다.

## 6. 로그인과 임시저장
- 비밀번호 로그인은 해외 IP라서 캡차가 뜹니다 → **QR 로그인**으로 바꿨습니다.
- GitHub 연결은 조직 설정으로 막혀 있어서, 압축 파일로 백업을 받아 직접 올리기로 했습니다.
- 임시저장 1차: 글자를 빠르게 직접 입력했더니 한글이 사라졌습니다.
- 2차: **서식 붙여넣기**로 해결했습니다. 저장 전에 초안과 한 줄씩 비교합니다.
- 1차 시험 글은 "이어서 쓸까요?" 창의 **취소 버튼 때문에 지워졌습니다.** 그 뒤로 이 창에서는 취소를 누르지 않도록 바꿨습니다.

## 7. 사용자 서식 지시 (최우선 규칙, STYLE.md 5-0)
- 글자 크기는 15로 통일합니다. 인용구로 만든 소제목만 19입니다.
- 강조는 색·굵게·밑줄·기울임으로 하고, 기본 이모티콘을 많이 씁니다. 강조는 더 많이 넣습니다.
- 본문과 정보 목록은 왼쪽 정렬합니다. 소제목은 **밑줄 인용구**로 만듭니다(이 스타일은 왼쪽 고정).
- 문장마다 줄바꿈합니다.
- 간격: 사진 → 글 → 빈 줄 3개. 소제목 앞에는 빈 줄 3~4개.
- 좋았던 점·아쉬웠던 점은 제목 바로 아래에 내용을 붙이고, 두 묶음 사이만 띄웁니다.
- ⭐주문메뉴⭐는 빼고 주문 메뉴는 분홍색으로만 표시합니다. 맛 후기 첫 줄에 주문 메뉴를 다시 적습니다.
- 맨 아래 순서는 **장소 지도 → 해시태그 20개 이상**입니다(검색량 기준).
- 맨 위 '위치 추가'는 블로그 앱 전용이라 앱에서 직접 합니다.
- **내돈내산 방문 인증**은 영수증 리뷰를 먼저 하면 글 맨 위에 넣습니다.
- 제목을 바꿨습니다. "마곡 라멘 맛집"은 월 110회뿐이었습니다.
  → `[마곡 맛집] 쿠로카메 라멘, 양천향교역 흑돼지 돈코츠라멘 만 원 솔직후기 🍜` (마곡맛집 39,680 · 양천향교역맛집 2,190 · 돈코츠라멘 8,750)
