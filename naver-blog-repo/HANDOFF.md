## 5. 글 한 편 만드는 순서 (자동화 흐름)
1. Drive `블로그` 폴더에서 사진/영상 받기 → HEIC를 JPG로 (`scripts/decode_drive.py`)
2. 세로 사진 가로 자르기 + **얼굴 모자이크** (`scripts/blur_faces.py`, 애매한 후보는 Claude가 눈으로 확인)
3. 영상이 있으면 GIF 만들기 (`scripts/make_gif.py`)
4. 가게 정보: 네이버 검색(주소·영업시간) + 그 가게 상위 블로그 10개 조사
5. 키워드: `scripts/keyword_volume.py`로 메인 1개 + 보조 2~3개 결정 (STYLE.md 6-1)
6. `drafts/build_<가게>.py` 작성 → `scripts/lint_post.py`로 점검 통과까지 수정 → 미리보기 HTML
7. `drafts/<가게>_spec2.json` 만들기 → `node automation/write_draft2.js drafts/<가게>_spec2.json` (로그인 상태 필요, 없으면 `automation/qr_login.js`로 QR 로그인)

## 6. 검색 노출 전략 요약 (자세한 내용은 STYLE.md 1, 6-1, 6-2)
- **조회수는 가게 선택에서 갈림**: 화제성(SNS·3대·웨이팅 숫자)·큰 상권·프랜차이즈 신메뉴 글이 상위, 강서권 동네 글은 하위. 추천 비율 화제·큰 상권 2 : 강서권 1
- 유입의 75%는 긴 꼬리 검색어. 건물·상권 키워드(예: `마곡 원그로브 맛집` 569회)가 지역 키워드 중 유입 1위
- 현재: 가게명 검색어는 1~15위, "마곡 맛집" 같은 큰 키워드는 30위 밖
- 계단식: 가게명 → 세부 키워드(`마곡 라멘 맛집`, `마곡 맛집 혼밥`) → `마곡 맛집`
- 강서권 집중, 방문 후 2~3일 안에 발행, 주 3회 이상
- 클립 영상(5~10초)을 맛 후기 부분에 넣기
- 제목 35~45자, 메인 키워드는 제목 맨 앞
