# 워드프레스 ETF 자동화 블로그 전략 (재민이와 의논, 2026-11 정리)

목표: 클로드 ↔ 워드프레스(MCP/REST API) 연결 → ETF 리포트 반자동 발행 → 애드센스 수익.

## 핵심 구조
- 비용: 국내 입문 호스팅(닷홈 1.5G / 카페24 일반형) + .com 도메인 ≈ 연 4~5만 원(월 3,300원).
- 역할 분담: 계산은 파이썬(yfinance·pandas·numpy), 글은 클로드, 발행은 사람.
  1. yfinance 주가·배당 수집 → 2. 파이썬 분석·WebP 차트(100KB 이하)
  3. 클로드가 7단계 템플릿으로 초안 + 내부 링크 → WP에 **임시저장(Draft)** (Application Password)
  4. 사람이 5분 팩트체크·의견 추가 → 예약 발행 (85% AI / 15% 사람)
- 네이버 블로그는 승인 후 보조 채널(같은 데이터를 구어체 요약).

## 7단계 ETF 글 템플릿
1. 기본 프로필(운용사·상장일·총보수·순자산·배당 주기) – 요약 표
2. 구성 종목·섹터(상위 10개) – 가로 막대 + 도넛
3. 상관계수(S&P500·TLT·GLD·BTC) – 히트맵
4. 유사 ETF 비교(예: SCHD vs VYM, 수수료·배당률·중복도) – 10년 누적 수익률
5. 역대 성과(CAGR·변동성·MDD) – 누적 곡선 + Drawdown
6. 30년 몬테카를로(1,000회: 최대·최소·중앙·평균·MDD) – 팬 차트
7. 목적별 참고 조합(안정형·성장형 백테스트, 권유 표현 금지) – 내부 링크 허브
- 한국 투자자 관점 필수: 배당소득세 15.4%, 환율, ISA·연금저축.
- 모든 글 하단: 운용사 공식 출처 링크 + "투자 권유 아님" 면책 (YMYL).
- Rank Math 80점 이상 유지(100점 집착 X).

## 로드맵
- 1주차: 호스팅·도메인·SSL·Rank Math·필수 페이지(소개·문의·개인정보처리방침).
- 2~4주차: 배당/성장/자산배분 3개 카테고리, 15~20편 하루 1~2편 예약 발행 → 서치 콘솔 색인 10~15개 확인 후 애드센스 신청.
- 2개월 차~: 몬테카를로·고단가 비교 키워드 확장, 주 5편.

## 클로드 검토 의견 (2026-11-18)
- 기술적으로 가능. 단 이 저장소는 폰 앱 클라우드 세션이라 "로컬 PC 클로드 코드" 대신
  클라우드에서 파이썬 실행 → WP REST API 호출. 필요한 것: 환경 네트워크 허용 호스트에
  내 WP 도메인 + Yahoo 금융 호스트 추가, WP Application Password는 request_credential로 저장
  (채팅에 붙여넣지 않기).
- 수익 가정이 낙관적: 자료의 RPM $7~8은 영어권 기준. 한국어 금융 트래픽 RPM은 대략 3천~8천 원.
  국내 검색은 네이버 비중이 크고, 구글은 AI 개요가 ETF 정보성 검색 클릭을 많이 가져감.
- 1년 뒤 예상(주 5편 ≈ 글 200~250개 가정): 월 3만~10만 원이 중앙값, 잘되면 20만~40만 원,
  월 100만 원은 1년 안에는 어려움(2~3년차 목표). 애드센스 반려·저품질 판정 시 0원 구간도 가능.

## 디자인 규칙 (2026-11-18 시안 기준)
- 글꼴: Pretendard 하나로 통일 (사이트 본문·제목·차트). 본문 17px/행간 1.8, 숫자는 고정폭 숫자(tabular).
- 색: 주인공 ETF = 파랑 #2a78d6 (모든 글 동일), 비교1 주황 #eb6834, 비교2 청록 #1baf7a, 낙폭 = 빨강 #e34948.
  자산별 색 고정(같은 ETF는 어느 글에서나 같은 색). 배경 #fcfcfb, 글자 #0b0b0b / 보조 #52514e, 격자 #e6e5e0.
- 차트: 제목은 왼쪽 정렬·번호(①②…)·결론형 문구, 선 끝에 이름 직접 표시(범례 박스 최소화), 세로 격자 없음,
  축 하나만(이중 축 금지). 상관계수 = 파랑–회색–주황 대비 색, 대각선(1.00)은 회색 처리.
  몬테카를로 = 파랑 농도 구간(5~95%, 25~75%) + 중앙값 굵은 선, 오른쪽 끝에 값 표시.
- 차트 아래 한 줄: 출처(Yahoo Finance 등)·기준일. 이미지 가로 1200px, WebP 100KB 이하, 대체 텍스트(alt) 필수.
- 대표 이미지(구버전 남색 시안은 폐기) → 아래 '캐릭터 브랜드' 규칙을 따른다.

## 캐릭터 브랜드 (백호 마스코트, 2026-11-18 확정)
- 원본: `brand/character/` (wave, point-chart, smile-eyes, side-cheer, wave-tail). 사이트 전체 디자인의 기준.
- 브랜드 색: 하늘 배경 #AADAEB→#C7E8F4(세로 그라데이션, 캐릭터 배경과 동일), 글자 남색 #1C283A,
  강조 노랑 #FFDE6E(형광펜 밑줄), 포인트 분홍 #D64A62(VS·질문 강조), 카드 흰색. 차트 주인공 ETF 파랑 #2a78d6 유지.
- 썸네일 1200×630: 왼쪽 글자 / 오른쪽 캐릭터(가장자리 페더 처리로 배경과 이어 붙임). 요소는 4개 이하.
  남색 라벨 알약 → 초대형 티커(130~170px Bold) → 노랑 형광펜 한 줄 → 흰 칩 3개(같은 폭, 라벨 28px·값 60px, 작게 넣지 않기).
  **기본 썸네일 = A 분석형** (사용자 선택 2026-11-18).
  문구 3~6단어, 사실 숫자만. 130px로 줄여도 티커가 읽혀야 함.
  템플릿 3종: A 분석형(point-chart), B 숫자·시뮬형(side-cheer, "얼마 될까?" 흰 카드), C 비교형(wave, VS 원).
  글 종류별로 포즈 고정. 생성 스크립트 예시 `brand/scripts/thumbnail_demo.py`.
- 본문: "백호 한마디" 요약 박스(작은 얼굴 아이콘 + 연하늘 배경), 작성자 소개·파비콘도 캐릭터 얼굴.

## 운영 규칙 (사용자 지시)
- 캐릭터 이름: **백호**. 요약 박스 이름 "백호 한마디". 글투: 친근한 존댓말, 백호 말풍선은 짧은 반말.
- 사용자 의견이 필요하면 채팅으로 묻지 말고 **선택창(AskUserQuestion, 4지선다+기타)**을 띄워 고르게 한 뒤 글에 녹인다.
- 답변은 폰 가독성 위해 표를 줄이고 짧은 목록 위주.

## ETF별 사용자 의견 기록
- SCHD: 아직 미보유(관심·공부 중) / 장점 = 배당이 해마다 늘어남 / 아쉬운 점 = 최근 수익률 부진(기술주 비중 낮음) / 추천 대상 = 성장주와 섞을 분산용.
